# 记账本

一个零依赖、离线可用的网页记账应用。

## v5.4.1 账期修复

- 从其他页面进入月度明细时默认显示本期，页内仍可手动切换账期；云同步改变账期起始日后，自动校正本期，浏览历史时保留原起始日期的账期归属。

## v5.4 体验优化

- 单条及批量删除后提供 8 秒撤销窗口，恢复最近一次删除的账单。切换账本或导入数据会清除撤销入口；刷新后不保留。
- 点击今日页的日预算，可查看预算、截至前一天已支出、剩余预算、账期总天数、计算公式，以及当天和本期截至所选日期的超支情况。

## v5.3 体验优化

- 长按账单（电脑右键）显示「删除 / 多选」；多选后逐条勾选或全选，确认后批量删除。今日、明细、搜索结果均支持。
- 启动页移除全屏扫描纹理和头像滤镜，减少手机渲染异常；页面就绪后约 0.65 秒退出，不再等待所有图片和音乐，最长等待 2.5 秒。
- 新版本下载完成后提供「更新 / 稍后」提示，主动点击更新才刷新；未保存的记账内容请先保存。
- 自定义账期在启动、切换账本、导入和保存后保持正确归属。
- 批量删除只作用于当前视图的勾选记录，切换页面、日期、账期或搜索词自动退出管理。跨月批量操作可先用搜索筛选。
- 改善预算说明文字的对比度，并兼容旧备份中的未知分类搜索。

## 安装成 App（PWA）

在线版可以直接"装"成独立应用，离线也能用：

- **安卓**：Chrome 打开网址 → 菜单 →「安装应用」/「添加到主屏幕」
- **iPhone**：Safari 打开网址 → 分享 →「添加到主屏幕」
- **电脑**：Edge/Chrome 打开网址 → 地址栏右侧安装图标 →「安装」

安装后桌面出现爱弥斯图标，点开是全屏无地址栏的独立窗口；软件资源会缓存到本地，没网也能记账看图（云同步需要网络）。

## 使用方法

**在线版**：https://czgwhtc.github.io/wuthering-ledger/ （手机电脑浏览器直接打开；每个浏览器的账单相互独立）

**本地版**：双击 `index.html`，用 Chrome / Edge 等现代浏览器打开即可使用，无需安装、无需联网。手机浏览器打开同样适配。

## 功能

- **记一笔**：支出 / 收入、分类、日期、备注；点击账单可编辑，删除需二次确认
- **明细**：按月查看、上/下月切换、当月收支结余汇总、按日分组与每日小计
- **图表**：当月支出分类占比环形图、近 6 个月收支趋势柱状图
- **预算**：设置月度支出预算，明细页显示使用进度，已用超 80% 变橙、超支变红；日预算 = max(0, 月预算 − 本月截至前一天累计支出) ÷ 本月总天数，不扣当天及之后的支出，按分四舍五入。查看历史日期时以所查看日期为准；开启自定义账期后，按该账期截至前一天的剩余预算与总天数计算
- **数据**：导出 JSON 备份 / 导入恢复 / 导出 CSV（Excel 可直接打开）
- **多账本（数据隔离）**：不同设备/浏览器打开天然独立；多人共用同一浏览器时，在「我的 → 账本」里各建各的账本，数据完全隔离、互不可见
- **云同步（自动）**：「我的 → 云同步」填一次 GitHub gist 令牌和同步密码（只存本机），之后自动后台同步：启动时、每次记账后、切回页面时、每 5 分钟。多设备同时记账自动合并（新增合并、编辑取较新、删除保留防复活）；数据 AES-GCM 加密后存你 GitHub 的私密 Gist
- **背景**：内置 39 位五星限定角色的官方海报（官网资源，`assets/bg-01`~`bg-39`），每 10 秒自动轮换；想换图替换同名文件、并在 `app.js` 的 `BACKGROUNDS` 里调整即可
- **角色主题**：每个分类用一位共鸣者的头像当图标（来自鸣潮 BWIKI，`assets/chara/`），记一笔弹层右侧随机出现一位角色立绘；在 `app.js` 顶部的 `CATEGORIES` / `CHARA_ARTS` 里可自行调整角色与分类的对应
- **背景音乐**：打开页面后首次点击会开始播放《繁星，新生，与你 Astrum Unicum》（鸣潮 OST，`assets/music/bgm.mp3`），右上角按钮可暂停/继续；想换曲子就把文件替换成自己的 mp3（文件名保持 bgm.mp3）

## 数据说明（重要）

- 账单保存在**当前浏览器**的本地存储（localStorage）中；仅开启云同步后，才会加密上传到你选择的 GitHub / Gitee。
- 换浏览器、换电脑、清除浏览器数据都会导致账单丢失，请定期在「我的 → 数据管理 → 导出备份」保存 JSON 文件。
- 恢复数据：在新浏览器打开本页面后，通过「导入备份」选择之前导出的 JSON 文件。

## 文件结构

- `index.html` 页面结构
- `style.css` 样式
- `app.js` 逻辑（数据存储、页面渲染、SVG 图表）
- `updates.js` 新版本提示与更新检查
- `record-actions.js` 长按菜单与多选交互
- `sw.js` 离线缓存
