# 记账本

一个零依赖、离线可用的网页记账应用。

## 使用方法

**在线版**：https://czgwhtc.github.io/wuthering-ledger/ （手机电脑浏览器直接打开；每个浏览器的账单相互独立）

**本地版**：双击 `index.html`，用 Chrome / Edge 等现代浏览器打开即可使用，无需安装、无需联网。手机浏览器打开同样适配。

## 功能

- **记一笔**：支出 / 收入、分类、日期、备注；点击账单可编辑，删除需二次确认
- **明细**：按月查看、上/下月切换、当月收支结余汇总、按日分组与每日小计
- **图表**：当月支出分类占比环形图、近 6 个月收支趋势柱状图
- **预算**：设置月度支出预算，明细页显示使用进度，已用超 80% 变橙、超支变红
- **数据**：导出 JSON 备份 / 导入恢复 / 导出 CSV（Excel 可直接打开）
- **多账本（数据隔离）**：不同设备/浏览器打开天然独立；多人共用同一浏览器时，在「我的 → 账本」里各建各的账本，数据完全隔离、互不可见
- **云同步（自动）**：「我的 → 云同步」填一次 GitHub gist 令牌和同步密码（只存本机），之后自动后台同步：启动时、每次记账后、切回页面时、每 5 分钟。多设备同时记账自动合并（新增合并、编辑取较新、删除保留防复活）；数据 AES-GCM 加密后存你 GitHub 的私密 Gist
- **背景**：内置 39 位五星限定角色的官方海报（官网资源，`assets/bg-01`~`bg-39`），每 10 秒自动轮换；想换图替换同名文件、并在 `app.js` 的 `BACKGROUNDS` 里调整即可
- **角色主题**：每个分类用一位共鸣者的头像当图标（来自鸣潮 BWIKI，`assets/chara/`），记一笔弹层右侧随机出现一位角色立绘；在 `app.js` 顶部的 `CATEGORIES` / `CHARA_ARTS` 里可自行调整角色与分类的对应
- **背景音乐**：打开页面后首次点击会开始播放《繁星，新生，与你 Astrum Unicum》（鸣潮 OST，`assets/music/bgm.mp3`），右上角按钮可暂停/继续；想换曲子就把文件替换成自己的 mp3（文件名保持 bgm.mp3）

## 数据说明（重要）

- 所有数据只保存在**当前浏览器**的本地存储（localStorage）中，不上传任何服务器。
- 换浏览器、换电脑、清除浏览器数据都会导致账单丢失，请定期在「我的 → 数据管理 → 导出备份」保存 JSON 文件。
- 恢复数据：在新浏览器打开本页面后，通过「导入备份」选择之前导出的 JSON 文件。
